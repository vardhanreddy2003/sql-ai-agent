Table: orders

Description:
Stores customer orders.

Columns:
order_id
customer_id
order_date
order_status
amount
discount
tax
shipping_charge
payment_method
payment_status
shipping_address
delivery_date
created_at
updated_at

Relationships:
Each order belongs to one customer.
One order can contain many order items.
Each order has one payment.
Each order has one shipment.
